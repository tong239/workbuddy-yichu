# 我的衣橱

手机端「衣橱管理」App：添加衣物、按季节/品类/颜色/状态筛选、搭配套图、想买清单、收藏、统计。

提供两种形态：

| 形态 | 文件 | 特点 |
|------|------|------|
| **安卓安装包（单机版）** | `我的衣橱.apk` | 直接安装到手机，数据存在手机本地，无需服务器 |
| **多人共享版（网页）** | `server.js` + `index.html` | 部署到服务器后，多设备多人实时协同编辑 |

## 零、核心亮点之一：App 内一键更新（免重装）

改功能再也不用重新发 APK。把本项目部署到服务器后，服务器就是你的**更新源**：

1. App 里：右上角 **⋯ → App 更新** → 填服务器地址（如 `https://xxx.onrender.com`）→ 保存
2. 点 **🔄 立即检查更新** → App 下载最新版 HTML 到本地并立即生效
3. 之后每次打开 App 会**静默检查**，有新版本时首页顶部出现「有新版本可用」提示条
4. **↩️ 恢复内置版本**：一键回退到出厂版本（不会动你的衣物数据）

原理说明：
- App 启动时优先加载本地缓存版本，没有才用内置版本
- 更新只替换页面代码，**localStorage 里的衣物数据完整保留**
- 版本判定依据服务端 `/version.json`（内含文件 MD5 前 8 位），文件内容一变版本号就变
- 可选两种更新通道：**离线单机版**（`/mobile.html`）与 **联网共享版**（`/index.html` + 服务端 API）

> 重要：因为更新的是 App 内的页面文件，**服务器地址必须能长期访问**（推荐 Render 免费部署）。

## 零000、核心亮点之四：地级市定位 + 男女分款推荐

**定位到市/区县/镇**
- 自动定位后按**省 → 地级市 → 区县**逐级解析，显示如 `📍 苏州市 · 昆山市 · 张浦镇`
- 反查链：**高德（填了 Key 时，能到镇/街道）→ BigDataCloud → OSM → wttr.in**
- **🔍 搜索城市**：设置里输入城市名搜索并切换（天气按坐标取，与地名独立）
- **📍 手动补镇/街道**：国际服务在国内拿不到镇级（实测 Open-Meteo 搜索"昆山"会返回福建同名地），所以在设置里填一次「张浦镇」即可永久显示，之后每次定位都会保留
- 断网也能用：手动填温度 + 天气状况

> 想全自动精确到镇：到 console.amap.com 免费申请 Key（服务平台选「Web服务」），填进设置即可

**男女分款推荐**
- 设置里选「我的性别」：女 / 男 / 通用（存本地，立即生效）
- 推荐只从**标记为对应性别或通用**的衣物里挑选，理由里会说明「已按女装筛选」
- **性别也会自动识别**：名称里写「男士羊毛大衣」→性别=男；「女士碎花裙」→性别=女；没写就是通用
- **智能降级**：某性别衣物凑不出一套（比如女装缺外套）时，自动放宽到全部衣物并明确提示「建议补充外套/下装」
- 添加衣物时可手动改性别（男/女/通用）

## 零00、核心亮点之三：输入名称自动识别

添加衣物时，只要输入名称，App 会**实时识别并自动圈选**品类 / 季节 / 颜色 / 价格，输入框下方显示识别来源：

| 输入 | 自动识别结果 |
|------|-------------|
| 燕麦色大衣 | 品类=外套，季节=秋冬，颜色=燕麦 |
| 卡其色薄款风衣 | 品类=外套，季节=春秋，颜色=燕麦 |
| 藏青加厚羽绒服 899元 | 品类=外套，季节=秋冬，颜色=蓝，价格=899 |
| 白色基础T恤 | 品类=上衣，季节=按当前月份，颜色=白 |
| 随便一个东西 | 品类/颜色/价格**留空不填**，季节按当前月份 |

规则要点：
- **品类**：内置 80+ 别名（大衣/风衣/羽绒服→外套；T恤/毛衣/针织衫→上衣；牛仔裤/阔腿裤→裤子；马丁靴/运动鞋→鞋子…）
- **季节优先子节点优先级**：名称里写明春夏秋冬 > 品类自带季节（风衣/针织/卫衣→春秋）> 保暖词（加厚/羽绒/毛呢→冬）> 清凉词（雪纺/短袖/亚麻→夏）> 读不到就按当前月份自动取
- **「没有就不填」**：名称里没有的信息一律留空，不会拿上一次的残留值
- **未知名词自动新增品类**：输入「瑜伽服」「汉服」「防晒冰袖」会自动建成新品类并记住（服务端/APK 均持久化）
- **手动优先**：你手动点选过的字段不会被覆盖；要重新识别点 **↺ 重识别**；也可关闭 **🔎 自动识别** 开关

## 零0、核心亮点之二：智能穿搭推荐

进入「智能搭配」页，App 会：

1. **获取你所在城市的实时天气**（自动定位，或手动选城市/手填温度）
2. **读取你衣橱里的全部衣物**（品类、季节、颜色、名称里的厚薄关键词、是否待清洗）
3. **智能打分生成今日穿搭**，考虑：
   - 温度分层：羽绒/毛呢→严寒；薄外套→15~22℃；短袖/雪纺→高温
   - 天气状况：下雨避开裙装、优先防水外套与靴子；下雪优先靴子与厚外套
   - 季节标签：优先选出标注了该季节的单品
   - 颜色协调：中性色安全搭配，避免红配绿等冲突
   - 穿搭新鲜度：记录「今天穿这套」的历史，自动避开最近几天穿过的单品
   - 干净优先：待清洗衣物降权，并给出提示
4. 可「🎲 换一套」轮换多达 6 套候选，「💾 存为搭配」或「✅ 今天穿这套」

> 天气数据来源：Open-Meteo（免费、无需 Key），失败自动切换 wttr.in；完全离线时可用右上 ⚙️ 手填温度，推荐照常工作。
> APK 版已内置定位权限；首次打开请允许定位，否则可选择城市/手填。

## 一、安装 APK（一加/OPPO/安卓通用）

1. 把 `我的衣橱.apk` 传到手机（微信文件传输 / 网盘 / 数据线均可）
2. 点开 APK → 系统提示「未知来源应用」→ 选择**仍要安装 / 允许**
3. 安装完成，桌面出现「我的衣橱」图标
4. 注意：APK 是**单机版**，数据只存在这台手机；卸载或清理应用数据会丢失，重要照片建议截图备份

## 二、多人共享版（多设备一起编辑）

数据保存在后端服务器上（`.data/store.json`），通过「房间(room)」隔离：链接里 `?room=名称` 不同，就是不同的共享衣橱。

### 本地运行

```bash
cd 我的衣橱
npm install
npm start
```

浏览器访问 `http://localhost:3000`；同一 WiFi 的手机访问 `http://电脑局域网IP:3000`。

### 部署到公网（推荐 Render 免费托管）

1. 把本文件夹上传到 GitHub 仓库
2. https://render.com → New → Web Service → 关联仓库（按 `render.yaml` 自动配置）
3. 部署后得到 `https://xxx.onrender.com` 网址
4. 把网址发给朋友即可，任何设备打开同一链接实时同步

### 多人协作

- 点 App 顶部「📋 复制邀请链接」发给朋友
- 朋友打开自动进入同一房间；任何人增删改，其他设备几秒内自动刷新
- 改链接里的 `?room=名字` 即可创建新的独立衣橱

## 三、共享版装成手机 App（PWA）

部署后用手机浏览器打开网址：
- iPhone（Safari）：分享 → 添加到主屏幕
- 安卓：菜单 → 安装应用 / 添加到主屏幕（已配置 manifest + Service Worker，支持离线打开）

## 四、目录说明

```
我的衣橱/
├─ 我的衣橱.apk    # 安卓安装包（单机版，含 App 内更新能力）
├─ server.js       # 后端：REST + SSE 实时推送 + 文件存储
├─ index.html      # 共享版前端（由 server.js 托管）
├─ manifest.webmanifest / sw.js / icon.svg  # PWA 支持
├─ package.json    # 依赖
├─ render.yaml     # Render 一键部署配置
├─ 我的衣橱.html   # 纯网页单机版（无服务器可用）
└─ .data/          # 运行时自动生成，各房间数据
```

## 五、注意事项

- APK 版与共享版数据不互通（一个在手机本地，一个在服务器）
- 共享版数据存在服务器，删除 `.data` 会丢数据，重要内容截图备份
- 当前为共享房间模式，无登录鉴权；需要权限控制可再加登录
